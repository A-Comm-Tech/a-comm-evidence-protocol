# site/

Status: **draft**. Planning material for a public website about the A-Comm Evidence Protocol (AEP).

This directory holds the information architecture and a homepage wireframe. It is not a published site and contains no production code. It does not change the specification. The normative text is in [`spec/`](../spec/).

| File | What it is |
|---|---|
| `information-architecture.md` | Sitemap, navigation, page purposes and outlines, the rules for what the site may claim, and a proposed build and deploy plan |
| `homepage-wireframe.html` | Static, self-contained homepage wireframe (light mode) |
| `homepage-wireframe.png` | Rendered image of the wireframe |

All hashes and chain data in the wireframe are illustrative. They do not correspond to any real transaction.
