# Core Specification & Schemas — Charter

**Status:** Provisional (pending member vote)

## Scope
Standardizing artifact schemas, cryptographic hash-chain primitives, and serialization protocols under strict SemVer discipline.

## Out of scope
Network-specific mappings (dispute-network-rules), identity and consent artifacts (identity-delegation), and client code (reference-implementations).

## Outputs
Schema and serialization drafts, errata, and the release path for core changes.

## Relationship to the spec
Owns the core of `spec/`. Any change to hash or signature semantics is MAJOR and requires this group's sign-off (spec §0.2, GOVERNANCE.md).
