# Dispute Resolution & Network Rules — Charter

**Status:** Provisional (pending member vote)

## Scope
Aligning exportable AEP bundles with global payment network dispute rules, automated representment pipelines, and chargeback reason codes.

## Out of scope
Core hash and schema changes (core-spec-schemas). Claims about network rules must cite the primary source; this group does not assert liability positions.

## Outputs
Export-profile drafts, reason-code mappings, and representment-pipeline guidance.

## Relationship to the spec
Proposes additions through the normal MINOR path. Once chartered to publish versioned profiles, outputs move to `profiles/`, subject to confirming that spec §0.2 allows independent profile versioning.
