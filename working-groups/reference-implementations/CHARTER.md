# Reference Implementations & SDKs — Charter

**Status:** Provisional (pending member vote)

## Scope
Maintaining production-ready, open-source client libraries across Python, TypeScript, Go, and Rust.

## Out of scope
Normative text. Conformance is defined by `vectors/`, never by an implementation.

## Outputs
The conformance matrix, an unranked list of independent implementations, and additional test vectors. SDK code lives in separate repositories because toolchains and release cadences differ; this folder links to them.

## Relationship to the spec
Contributes vectors to `vectors/`. Must provide matching vectors for any MAJOR change before editors merge it.
